**Prerequisites**: The revised fixed `openai_responses` design is authoritative; implement no alternate provider or configurable endpoint, model, or proxy behavior.

**Tests**: Required. Write tests before the implementation they prove. The frontend has `dev`, `build`, and `preview` only: verify UI behavior with its production build and a real-browser synthetic fixture, not an invented frontend test framework.

**Format**: `[ID] [P?] [US#?] Description`

- `[P]` identifies distinct-file work with no unmet dependency; shared hotspots are not marked parallel.
- `[US#]` occurs only in user-story phases. Setup, Foundational, and Cross-cutting work have no story label.
- Every new Go source and test file carries `//go:build windows`.
