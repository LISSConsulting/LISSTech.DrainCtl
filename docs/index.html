LISSTech DrainCtl

Real-time Remote Desktop Session Host drain mode monitoring. Know the instant someone flips the switch — and who did it.

View on GitHub Download MSI

Why DrainCtl?

🔔

Real-time Detection

RegNotifyChangeKeyValue fires the instant TSServerDrainMode changes. No polling delay.

📋

90-Day Audit Trail

Every state observation logged to JSONL. Track transitions, durations, and patterns over time.

👤

Change Attribution

EvtSubscribe on Event ID 4657 identifies who changed drain mode, delivered in under a second.

🐚

PowerShell Native

Get-RDSHDrainMode, Test-RDSHDrainMode, Get-RDSHDrainHistory. Pipeline-friendly objects.

Quick Start

# Install (silent) msiexec /i LISSTech.DrainCtl.msi /qn # Check drain mode (instant via service pipe) drainctl check [OK ] status=Healthy connections_allowed=true exit=0 # PowerShell Get-RDSHDrainMode if (Test-RDSHDrainMode) { "OK" } else { "ALERT" } # View audit history Get-RDSHDrainHistory -ChangesOnly -Limit 5
